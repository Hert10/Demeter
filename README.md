# Demeter

Ce projet est une plateforme Big Data d'aide à la décision destinée aux agriculteurs. Son objectif est d'anticiper les événements climatiques extrêmes (comme la sécheresse ou les inondations) grâce à l'analyse prédictive. L'architecture technique combine un traitement de données distribué avec Hadoop et Spark (MLlib) pour le Machine Learning, et une interface utilisateur en Next.js pour la visualisation des risques en temps réel.
